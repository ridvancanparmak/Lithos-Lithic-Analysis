# Checklist before publishing publicly

- [ ] No research data files (`*.accdb`, `*.mdb`, reports, field lists with personal data) committed
- [ ] No passwords, API keys or access tokens committed
- [ ] Contact email shown in app's About panel is intended to be public
- [ ] Asset provenance and rights checked (including icons, flags and concept artwork)
- [ ] README clearly distinguishes approved design mock-up from running application
- [ ] Windows binary and Access generation not claimed as tested until verified
- [ ] A license has been chosen deliberately (or source published with no license)
- [ ] Official release contains tested installer only, not an untested binary
